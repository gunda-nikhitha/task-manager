# TaskFlow — Task Manager App

A clean, minimal task manager built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies — just pure front-end skills.

## Live Demo
>https://gunda-nikhitha.github.io/task-manager

---

## Features

- Add tasks with a title, due date, and priority level (low / medium / high)
- Mark tasks as complete with a single click
- Due date badges — shows **Overdue**, **Today**, **Soon**, or the date
- Filter tasks by: All · Active · Completed · Overdue
- Clear all completed tasks at once
- Stats bar showing total, done, and overdue counts
- **Data persists in localStorage** — your tasks survive page refresh
- Fully responsive — works on mobile and desktop

---

## Tech Stack

| Layer    | Technology              |
